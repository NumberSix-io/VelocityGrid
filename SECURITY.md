# Security policy

VelocityGrid has not yet published a stable supported release line. Security fixes target the current main development branch.

Do not disclose a suspected vulnerability in a public issue. Use GitHub private vulnerability reporting and include affected commits, reproduction, impact, and mitigation. If private reporting is not enabled when the repository becomes public, contact the repository owner privately to request a reporting channel without publishing exploit details.

Ordinary crashes, provider errors, performance regressions, and feature requests that do not cross a security boundary may be public issues.
